Help Center

Try these basic troubleshooting steps before submitting a ticket.

Network Problems

  1. Check that Wi-Fi is enabled.
  2. Disconnect and reconnect to the network.
  3. Restart your device.
  4. Submit a ticket if the issue continues.

Login Problems

  1. Check your username and password.
  2. Make sure Caps Lock is turned off.
  3. Try resetting your password.
  4. Contact IT if you still cannot log in.

Printer Problems

  1. Check that the printer is powered on.
  2. Check the paper and cable connections.
  3. Cancel and resend the print job.
  4. Submit a ticket if the issue continues.

Still Need Help?

If the problem continues, create a support request.
