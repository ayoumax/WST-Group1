# MotorPH IT Support Ticketing System

A browser-based IT support ticketing system for MotorPH employees, IT technicians, and administrators.

## Project Overview

The system allows MotorPH employees to submit and monitor IT support tickets. IT technicians can review assigned tickets, update ticket status, and respond to employees, while administrators can monitor all tickets and assign technicians.

## Current Features

### Employee
- Employee login
- Employee dashboard
- Submit IT support tickets
- View submitted tickets
- View ticket details and status
- Send comments/messages to IT support
- Access basic troubleshooting help

### IT Technician
- IT technician login
- Technician dashboard
- View assigned tickets
- Search and filter tickets
- Review ticket details
- Update ticket status
- Respond to employees

### Administrator
- Administrator login
- Administrator dashboard
- View all support tickets
- Monitor ticket status
- View assigned technicians
- Assign technicians to tickets

## Technologies

- HTML
- Visual Studio Code
- Live Server

## Current Development Stage

The project currently contains the merged and organized HTML structure for the Employee, IT Technician, and Administrator roles.

The current version focuses on page structure, navigation, forms, tables, and role-based workflows.

CSS styling, JavaScript interactivity, data persistence, and backend/database functionality will be added in later development stages.

> Note: Forms and buttons are currently part of the static HTML prototype and do not yet save or update actual data.

## Project Structure

- `index.html` - Main login page for Employee, IT Technician, and Administrator
- `employee-dashboard.html` - Employee dashboard
- `submit-ticket.html` - Employee ticket submission form
- `my-tickets.html` - Employee submitted ticket list
- `ticket-detail.html` - Employee ticket details and message section
- `help.html` - Basic IT troubleshooting help page
- `technician-dashboard.html` - IT Technician dashboard
- `manage-tickets.html` - Technician ticket management page
- `admin-dashboard.html` - Administrator dashboard and ticket assignment page

## Current Workflow

### Employee
`Login → Dashboard → Submit Ticket / My Tickets → Ticket Details → Help`

### IT Technician
`Login → Technician Dashboard → Assigned Tickets → Manage Ticket`

### Administrator
`Login → Administrator Dashboard → View All Tickets / Assign Technician`
