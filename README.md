# MotorPH IT Support Ticketing System

A browser-based IT support ticketing system for MotorPH employees and IT administrators.

## Project Overview

The system allows employees to submit and monitor IT support tickets, while IT administrators can review, respond to, and manage employee support requests.

## Current Features

### Employee
- Employee login page
- Employee dashboard
- Submit IT support ticket
- View submitted tickets
- View ticket status
- Send messages to IT support

### IT Admin
- IT admin login
- IT admin dashboard
- View support tickets
- Search and filter tickets
- Update ticket status
- Respond to employees

## Technologies

- HTML
- Visual Studio Code
- Live Server

## Current Development Stage

This project currently contains the initial HTML structure. Styling, JavaScript interactivity, and backend functionality will be added in later development stages.

## Project Structure

- `index.html` - Login page
- `employee-dashboard.html` - Employee dashboard
- `submit-ticket.html` - Submit ticket form
- `my-tickets.html` - Employee ticket list
- `admin-dashboard.html` - IT admin dashboard
- `manage-tickets.html` - IT ticket management page
